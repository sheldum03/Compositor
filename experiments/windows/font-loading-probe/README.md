# Local font loading feasibility probe

M1 experiment for TTF, CFF OTF, and both faces of the existing unsigned TTC v1 fixture. No production importer or system font installation. Uses Avalonia 11.3.22 / SkiaSharp 2.88.9 and explicitly opts into `AvaloniaAccessUnstablePrivateApis`; the build warning is intentional and this dependency is a selection cost.

```sh
dotnet run --project experiments/windows/font-loading-probe -- <font-fixtures-directory>
dotnet run --project experiments/windows/font-loading-probe -- <font-fixtures-directory> --raw
```

The first invocation must return 0; `--raw` is a failing control (exit 1) that loads the unchanged TTC stream for both requested indices. It must fail only the second face. Fixed fixtures are generated by `scripts/windows/generate-font-fixtures.py`; no third-party font is modified.

Checks exact weight, A advance at size 100, `AB` layout width, reference identity of the layout's glyph typeface, unchanged source hashes, and rejection of three existing damaged fixtures. The temporary TTC adapter swaps directory offsets in a private byte array so the requested face is first; it does not rewrite any table or input file. It deliberately supports only this unsigned TTC v1 experiment. Signed/TTC v2 files, PostScript-name lookup, arbitrary font collections, limits, conflicts, persistence and UI import still belong to a complete font implementation. Do not copy this helper directly into production.

The Mac native Skia indexed-file call is recorded separately; a null result reports advance -1, never the width of a default font. It does not determine the main pass result. Windows must run separately because the native font backend differs.

`run-windows.py` consumes a private manifest kit under `CompositorTest`, verifies 19 existing Windows dependencies and the official runtime inventory, then copies only those dependencies plus the four new probe assets to a fresh output directory. It runs raw and adapted controls and archives the reports even on failure. `productionFontImportAccepted` stays false.

Sources: [Avalonia stream loader](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/src/Skia/Avalonia.Skia/FontManagerImpl.cs), [font source identifiers](https://github.com/AvaloniaUI/Avalonia/blob/11.3.22/src/Avalonia.Base/Media/FontFamily.cs), [OpenType collection header](https://learn.microsoft.com/en-us/typography/opentype/spec/otff#font-collections). See the corresponding evidence record for actual execution and limitations.
