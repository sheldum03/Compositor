# Compositor Windows 生产入口

Avalonia 11.3.22 / .NET 10.0.401，使用已选定的软件绘制路线。此项目引用正式 Core/Imaging；原型代码不进入应用。当前是内部集成窗口，尚未达到 M3 Alpha。向下合并支持受限平面层，以及选中连续同级根图层时把完整组子树合成为单一平面层；复杂组关系仍会拒绝。

```sh
cd windows
dotnet restore Compositor.App/Compositor.App.csproj --locked-mode
dotnet run --project Compositor.App -c Release --no-restore
```

当前操作：新建透明画布，设置整数像素宽高和 DPI（默认 1920×1080、72 DPI，总像素不超过 100 MP）；选择 `.comp` 文件夹打开工程；PNG/JPEG 导入为新工程；同一窗口内打开多个工程标签并切换/关闭；平面图层的新增、复制、选区复制为新图层、删除、改名、显隐、上下移动、图层列表拖放排序、受限 Normal/非 Normal 平面层向下合并、连续多选合并、受限连续剪贴栈合并、受限非恒等变换合并，以及连续同级根组与下方同级图层的组子树合并，透明度 0–100%、13 种混合模式和撤销/重做；受限 pass-through 组的加载、蒙版启停、反相、填白/填黑/模糊、组移动/翻转/缩放/旋转及变换组烘焙解组；保存、另存为新 `.comp` 文件夹；透明 PNG 或白底/质量 95 的 JPEG 导出。预览和导出使用同一核心合成结果，像素复制到 Avalonia 的预乘 RGBA bitmap。文件操作和图层命令在后台执行，期间禁用编辑，避免重叠操作。

画布支持滚轮围绕鼠标位置缩放、中键或空格加左键平移、适合窗口、100% 视图和 4 倍以上的像素网格。矩形/椭圆/魔棒/套索选区工具和清除选区只改变当前会话的内存选区，不标脏；支持替换、加选、减选和半径可调的选区羽化，魔棒使用当前合成预览和原生 C 算法，套索按指针路径填充多边形，选区会限制软笔的像素提交。平移、缩放、翻转和旋转后的平面图层会把文档坐标映射回源栅格，选区、软笔和全画布蒙版编辑可继续使用；逐层复制/剪切/粘贴会保留变换坐标，只有跨变换快照时才要求先烘焙。可从当前图层 Alpha 载入选区。复制、剪切、粘贴使用会话内选区快照并进入像素历史；同一窗口的兼容工程标签也可共享复制快照，粘贴先进入浮动选区，取消不修改目标工程；粘贴恢复到原选区位置。当前图像复制会尽力写入系统剪贴板，系统剪贴板中的位图可用 Ctrl+V 或“粘贴选区”作为居中新图层导入，超出画布部分会裁剪；系统剪贴板不可用时内部工程剪贴快照仍可用。移动选区会同时移动当前图层的选中像素和选区蒙版，越界像素裁剪到画布；像素变化可撤销，选区本身仍是会话态。按住 Shift 拖动笔划会约束为水平或垂直直线；图像和 Gray8 蒙版在宽高同时缩小时使用面积覆盖下采样，上采样或混合轴缩放保留双线性路径；Lanczos 和大图性能仍待验收。运行魔棒需要将与当前平台匹配的 `compositor_native` 动态库放在应用目录；缺少库或调用失败时保留当前选区并显示错误。软笔在选中图层绘制，可设置直径 1–2000、不透明度 1–100% 和四种颜色。移动时仅临时预览，松开提交一个历史步骤；Esc、指针捕获丢失、窗口失去活动状态或关闭取消未提交笔划。绘制期间禁用文件和图层操作。当前笔划预览在 UI 线程完整合成并更新位图，尚无生产性能结论。

新建文档在首次成功保存前保持未保存状态；保存先选择存放位置和名称。关闭或替换有修改的工程时提供保存、不保存、取消；保存失败或取消保持原文档和窗口。打开失败、取消新建及无效尺寸不替换当前会话。另存和导出目前要求新路径，拒绝覆盖已有其他工程/文件。Ctrl+N/O/S/Z/Y/C/V 可用于工程操作；名称输入框保留自己的文本快捷键。选层不产生撤销步骤，结构撤销会恢复活动层；删除最后一层得到可保存的空工程，仍可新增或撤销恢复。

不在受限白名单内的组、文字、形状和其他复杂 v8 语义会明确拒绝编辑；组根合并只接受连续同级选择，并要求组子树内的剪贴关系完整。v1 非默认外观仍只读；v8 平面图层的透明度和 13 种混合模式通过同一合成器预览/导出。当前选区已支持矩形/椭圆/魔棒/套索替换、加选、减选、清除、从图层 Alpha 载入、原位复制/剪切/粘贴、选区复制为新平面图层及当前图层像素移动，浮动选区事务和全画布 Gray8 蒙版编辑已接通；选区复制为图层支持平面图层（包括其受限蒙版/剪贴可见结果、非破坏变换和非 Normal 源外观），复制结果写入新的默认 Normal 像素层，组和复杂语义不会静默转换；跨工程粘贴要求相同画布尺寸和未变换平面目标，平面源的非恒等变换会先按文档坐标归一后进入目标浮动选区，同工程浮动选区仍只接受同一变换快照，组源、失效快照和复杂语义明确拒绝，魔棒依赖匹配平台的原生动态库。该入口尚无完整文字/字体编辑、完整快捷键、恢复界面或安装器；不得作为 Alpha/Beta 发布。Windows 原生窗口、首次保存文件夹选择、IME/DPI、设备及性能验证尚未完成；13 模式的真实 Mac exact 对照仍是生产门槛。

窗口检查单独位于 `Compositor.App.Checks`，Headless 不进入生产项目依赖：

```sh
dotnet restore Compositor.App.Checks/Compositor.App.Checks.csproj --locked-mode
dotnet run --project Compositor.App.Checks -c Release --no-restore -- Compositor.Imaging.Checks/fixtures <新的输出目录>
```

检查会真实构造窗口控件、点击命令与确认对话框，验证预览字节、历史、脏状态、失败保存及关闭保护，并生成窗口 PNG。画布检查另比较固定 M1 的三组笔划临时/最终像素，模拟实际缩放、两种平移、指针提交、取消/丢失捕获/关闭，验证单步撤销与保存导出。见[画布与软笔证据](../../docs/windows/evidence/production-canvas-brush.md)。Headless 通过不等同于原生 Windows 验收。思源黑体字体及 OFL 许可证随应用输出；完整第三方发行清单仍按 M7 门槛追踪。

新建窗口检查覆盖实际取消/无效尺寸/分数像素/创建对话框、未保存关闭与替换取消、图层按钮和选层、复制后独立绘画、保存空工程后撤销恢复并再次保存；首次选定路径由工作区 SaveAs 验证，原生文件夹选择尚未执行。见[新建与图层窗口证据](../../docs/windows/evidence/production-new-window.md)。透明画布的棋盘背景仅用于窗口显示，不写入工程或导出像素。
