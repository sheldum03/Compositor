依据：2026-09-21 实机记录、用户对第二版切页后拼音取消测试的通过反馈，以及 [W-001–040 开发计划](development-plan.md)、[P-01–19 产品需求](product-requirements.md)、[V-01–12 验收规则](validation-release.md)。本清单细化现有任务，不改变产品范围、框架选择或性能门槛。

2026-09-22 最新更新：第二版证据已归档，S02 本机固定工作负载的数值性能门槛已连续两轮通过：空层/已有层更新 P95 10.9458/11.3822 ms，复测 11.0144/11.3419 ms；提交、内存及原生预览精确性均通过。五轮原始证据和代码已整理，见[本轮计划与完成记录](evidence/s02-optimization/tail-followup.md)。后续优先原生生命周期/连续输入缺项、S05 资源增长、Qt 与设备矩阵；不再将本机 S02 更新超预算列为当前阻断。

本轮新增：S05 三轮原生重放已执行，300 编辑的正确性在远端报告为通过，但关闭后自然内存增长，资源稳定性未放行；原始包待解锁后取回。小视口拒绝暴露启动中退出异常，本地已修复，Windows 回归与中途关闭/连续输入待解锁。见[执行记录](evidence/lifecycle-s05/README.md)与[M1 评审草案](m1-selection-review.md)。

- 第二版 `c570953` 的“切页返回→全选→微软拼音 ceshi→Esc→原文保留”按用户实机反馈通过。112 项相关 Windows 自动回归也通过；本次没有独立比较原生取消前后 PNG。已通过的这一手动步骤无需再次要求用户确认。

## 第二批：建立生产核心（M2，W-010–015）

依赖：M1 选型完成。原型中已有能力需接入生产文档和事务系统，不能直接把探针判为生产功能。

1. **W-010 构建入口**：生产程序入口、固定依赖、Release 构建与 CI；干净构建能运行，共享代码修改触发 Mac 检查。CI 源码准备和远程实际执行分开记录。
2. **W-011 文档与历史**：图层 ID/层级、资产身份、编辑事务、撤销/重做、保存点与脏状态；取消无历史，切项目不串状态。
3. **W-012 像素核心**：RGBA/Gray、瓦片快照、局部更新、共享画布/离屏合成与 C 算法；新操作不能污染旧历史，预览与导出规则一致。
4. **W-013 工程读取**：v1–8 reader、默认值/资源/层级校验、未来版本及损坏工程拒绝；尚不支持的语义必须阻止编辑覆盖。
5. **W-014 安全保存**：快照、同卷临时目录、备份/替换与恢复、保存期间操作互斥；在各写入阶段注入中断后，完整旧版或完整新版可恢复。
6. **W-015 基础 IO**：PNG/JPEG 导入导出、EXIF/透明度、分辨率；导出不清除工程脏状态，失败不留下正式半成品。

阶段通过标准：无窗口入口也能复现“读取→编辑→合成→保存→重开→导出”，必要故障测试通过。

## 第三批：完成核心工作流和 Alpha（M3，W-016–022）

- **W-016**：主窗口、多项目、工具/图层/状态区、对话框、快捷键与 DPI 坐标；输入框不误触工具快捷键。
- **W-017**：图层/组增删、复制排序、显隐、透明度、13 混合模式与合并；组合工程逐项校验。
- **W-018**：基础选区、套索、魔棒、浮动选区及像素复制移动；区分选区移动与像素移动，取消和历史正确。
- **W-019**：连续软硬笔刷、笔尾和局部提交，栅格/组/剪贴蒙版及基本编辑；抬笔立即下一笔和撤销可靠。
- **W-020**：移动、缩放、旋转、翻转、裁剪、画布/图像尺寸及其选区/蒙版影响；非破坏变换不重采样原图。
- **W-021/022**：串联新建→导入→组/蒙版/笔刷→变换→保存→重开→导出，统一活跃操作提交/取消；先内部集成，再完成 Alpha 行为和便携包验收。

阶段通过标准：实际完成完整编辑流程，未支持的工程不会被误保存；核心数据丢失/崩溃阻断项为零。Alpha 不等于完整 1.0。

## 第四批：文本与字体（M4，W-023–025）

1. **W-023**：将已验证的输入能力接入正式文字层，完成点/框文本、单样式、字距/行距/对齐、中英/Emoji、IME、变换命中和统一导出布局；空文本取消无层/历史，既有层 ID/父组/效果保留。
2. **W-024**：内置思源字体、OTF/TTF/TTC 导入、TTC 多 face、重复去重、同名冲突、损坏拒绝、重启恢复；普通用户可用且许可随包。
3. **W-025**：v8 文字元数据与缓存读写；原字体可用时缩放重绘，缺字体时保留缓存和元数据并提示，取消不替换；明确替换、栅格化及尺寸操作支持撤销；保存重开与导出正确。

阶段通过标准：中英混排、Emoji、框文本、缺字体和导入字体都有原生流程和双端工程证据。第二版关闭 surrounding-text 支持的限制仍需评估，不能据此宣称重新转换等能力已通过。

## 第五批：高级编辑和完整性能（M5，W-026–030）

- **W-026/027**：色相饱和度、色阶/自动色阶、曲线、曝光、渐变映射、颗粒、反相、高斯/运动模糊、噪声、镜头校正；预览取消不改文档，提交一个历史步骤，透明边缘和全分辨率导出正确。
- **W-028**：渐变、形状、拾色器、调色板及参数保存重绘；重开后仍可编辑。
- **W-029** 分四组逐项验收：①修复/仿制/内容填充；②模糊/涂抹/液化；③自由扭曲、多层变换、吸附、独立蒙版及完整选区；④跨项目复制/拖放。
- **W-030**：完整 S01 平移缩放、S02 大软笔、S03 多层合成、S04 8K 压力、S05 连续编辑三轮；统计延迟分布、RAM/VRAM、上传/回读和稳定性，GPU 如被选用还需与 CPU 契约对照。

阶段通过标准：相关 P/V 项全量通过，S01/S02 达到冻结门槛，S03–S05 按各自预算和稳定性标准验收；不会把 8K 压力场景强行套用 S02 耗时。

## 第六批：完整兼容、AI 和 Beta（M6，W-031–035）

1. **W-031**：TIFF/HEIC、EXIF/ICC/DPI、JPEG 质量预览，真实相机及透明/色彩样本；实际发行包在无额外 codec 的干净机解码。
2. **W-032**：至少 30 张有使用权的 AI 样本，覆盖发丝/毛发、商品、透明边缘、低对比、多主体等；记录质量、首推/热推、内存、模型 hash/许可，决定生产模型与后端。
3. **W-033**：真实图片预后处理、可编辑蒙版、细化、模型获取/校验/缓存、进度/取消；下载断网、坏包、无模型和离线重启都可控，用户图片不上传。
4. **W-034**：全功能 v1–8 双向往返，保留文字/形状/蒙版/调整与层级；Mac 保存→Windows 修改→Mac 重开及反向均验证，取消 Alpha 的受限编辑保护前先补齐语义。
5. **W-035**：决定发行/更新工具，制作 Beta 候选安装包，跑完整用户流程和基础安装，冻结功能。

阶段通过标准：P-01–17、P-19 和 P-18 基础安装有完整记录；原型 AI 张量测试、HEIC 生成样本不能替代本阶段。

## 第七批：发布验收（M7，W-036–040）

- **W-036**：干净 Windows 普通用户安装/启动/卸载、依赖与离线可用；不删除用户工程或导入字体。
- **W-037**：唯一更新通路、包真实性/完整性、编辑中延后重启、旧→新；断网/坏包/文件占用后仍保留可启动版本。
- **W-038**：最终设备矩阵、100/150/200% DPI/跨屏、集显与所选 GPU、键鼠/基础数位笔、中文路径、剪贴板/拖放；损坏工程、锁定/只读/磁盘不足、保存中断、连续编辑资源复测。
- **W-039**：用户入门、快捷键、工程迁移、字体/模型说明、第三方清单和版本说明；准备签名材料与配置。
- **W-040**：从候选提交重新构建、签名、干净安装和升级冒烟；核对源码/依赖/包 hash/签名/设备结果一致，再执行获授权的正式发布。

最终通过标准：P-01–19、V-01–12 全部有通过记录；数据损坏、丢层/文字、保存误报成功、普通路径崩溃、升级无法启动等阻断为零。没有签名资源时只能交付明确标记的内部测试包。

## 推荐下一项与配合方式

第二版证据归档、S02 入队计时、已有层打包混合、直接合成和 GPU 对照已完成；下一轮以 direct 为基线，优先关联慢帧的调度/CPU 栈，解决已有层尾部延迟，同时按空缺清单安排原生输入和 Qt 对照。开发、构建、分析和用例准备由代理执行；需要本机输入法、真实连续鼠标/数位笔、集显或多屏环境时再逐项引导用户操作。

当前不承诺发布日期或完成百分比。M1 选型后，用实测成本为五类生产任务（数据/文件、渲染/像素、交互/事务、文本/字体、发行/依赖）估算人员和工期。后续记录以具体 W/P/V、提交、运行环境和产物为准。
