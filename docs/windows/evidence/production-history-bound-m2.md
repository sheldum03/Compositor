# M2 撤销步数与历史图像预算（2026-10-02）

`ProjectSession` 在每次正式提交后最多保留当前快照与 100 个可撤销快照；分支编辑仍删除被放弃的重做尾部。保存点快照即使移出可撤销范围，当前版本仍保持脏状态，直到再次成功保存。

工作流检查在已保存工程上连续改名 105 次，验证仅能撤销 100 次、边界为第 5 次提交、再重做 100 次，并确认从倒数第二步创建新分支后旧重做不再可用。包含像素编辑、保存重开、两层 Normal 工程合成及 Mac 产物反向编辑的 macOS arm64 Release 检查退出 0。

后续增加 256 MiB 历史独占瓦片字节预算。计算按瓦片数组对象身份去重：当前快照仍引用的共享瓦片不计入历史独占；超过预算时依次裁掉最旧的撤销状态。保存点改用版本号记录，因此被裁掉后不会继续持有整个旧快照；源图只有仍在当前或历史快照中才保留。Core 冒烟先用 300×300 的四瓦片图只改一个瓦片，断言独占历史只计旧瓦片的 262,144 字节；再连续提交 18 张 2048×2048 全幅图，验证预算始终不超过 268,435,456 字节、最终保留 16 步可撤销与完整重做，旧保存点已不可达时仍为脏。含原生 C 像素边界的 Core 冒烟和上述完整工作流均退出 0。

预算只覆盖快照持有的图像瓦片字节，不是进程 RAM 峰值，也不含元数据、字典、解码器或渲染缓存。预览事务与 Windows 实机长时间编辑仍未实现或验收，W-011/S05 不能据此关闭。
