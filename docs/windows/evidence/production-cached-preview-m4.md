# M4 文字/变换缓存只读预览（2026-10-05）

生产窗口现在能读取一类暂不支持编辑的 v8 工程缓存：图层保留 `text` 元数据和缓存 PNG 时，打开使用缓存像素，不根据缺失的 PostScript 字体静默换字；同时按图层 `origin`、`size`、`rotation`、`flipX`/`flipY` 将缓存绘制到文档画布。该工程以只读方式打开，导出和视图操作可用，保存、笔刷、选区、图层和变换命令禁用。

## 固定验证

`CanvasChecks` 从真实双层工程复制出独立工程，给顶层缓存图层写入缺失字体名、文字元数据以及 15° 旋转/水平镜像变换。检查验证工程 `CanEdit == false`、缓存预览存在、PNG 导出保持文档尺寸；正式窗口显示“缺失字体或文字语义未就绪，请先选择字体后再编辑”的只读提示；同一套检查还覆盖带全画布 Gray8 蒙版的只读预览。

固定 SDK 10.0.401、Avalonia Headless 11.3.22 的 Release 构建为 0 警告、0 错误；无原生库和带 `compositor_native` 动态库的 AppChecks 均退出 0。

## 边界

这只是缺失字体/缓存文字的保护和预览切片，不是 W-023–025 完成。当前没有点/框文字编辑、IME、字体目录导入/去重、缺失字体选择对话框、重新排版、v8 文字写回、组/调整层/蒙版源或 Windows 字体/DPI 验收。
