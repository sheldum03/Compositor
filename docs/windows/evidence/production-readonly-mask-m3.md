# M3 不支持蒙版工程的只读预览（2026-10-05）

生产窗口现在可以打开带全画布 Gray8 图层蒙版、但尚未支持编辑的 v8 `.comp` 工程。打开时沿用工程中的缓存图层和蒙版合成结果，不把工程误判成普通可编辑平面；保存、图层结构、变换、选区和笔刷命令被禁用，PNG/JPEG 导出和视图操作保留。

## 固定验证

`CanvasChecks` 从当前真实双层工程复制出独立 `.comp`，为顶层资产写入合法的全画布 Gray8 蒙版，然后通过 `EditorWorkspace.Open` 和实际 `MainWindow` 验证：

- 工程打开为 `CanEdit == false`，图层和缓存预览存在；
- 直接导出 PNG 后尺寸保持不变；
- 保存、90°旋转、矩形选区按钮禁用；
- 导出 PNG 按钮仍可用。

固定 SDK 10.0.401、Avalonia Headless 11.3.22 的 Release 构建为 0 警告、0 错误；无原生库和带 `compositor_native` 动态库的 AppChecks 均退出 0。

## 边界

当前只覆盖全画布 Gray8 蒙版的只读保护和缓存预览，不支持蒙版编辑、蒙版启停事务、组/剪贴蒙版、蒙版源关系或带文字/调整层/自由变换工程的完整缓存渲染；不能据此关闭 W-018、W-019、W-021 或 Alpha/Windows 验收。
