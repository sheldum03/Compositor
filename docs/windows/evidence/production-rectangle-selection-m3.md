# M3 基础矩形/椭圆选区（2026-10-05）

当前生产窗口已接入矩形/椭圆选区工具、替换/加选/减选组合和清除选区按钮。选区是 `EditorWorkspace` 的会话内 `GrayTileRaster`，不写入 `.comp` manifest，不改变保存点；新建、打开或导入工程会清除旧选区。选区拖动使用画布文档坐标，边界按像素边界稳定取整，并绘制在画布上。

软笔构造时捕获当前选区快照，笔划提交只在选区覆盖范围内改变像素。完全落在选区外的笔划不会产生空历史步骤；选区内笔划仍只提交一步，可撤销。清除选区不标脏，也不进入图像历史。

## 固定验证

`CanvasChecks` 在固定窗口中完成：矩形拖选 30–150 × 30–120，得到 120×90 的不透明选区；选区期间工程保持干净；选区外笔划保持原像素且不产生历史；选区内笔划改变像素并可一次撤销；第二个矩形加选后覆盖 16,000 像素，减选后覆盖 14,000 像素；椭圆替换得到非空且小于外接矩形的覆盖；清除选区后工程仍干净。原有软笔 exact、视图缩放/平移、100%/像素网格、保存导出及关闭取消回归继续通过。

该切片使用固定 Avalonia Headless 源码检查，未执行 Windows 物理鼠标、DPI、多显示器或性能验收。当前仍未接入套索/自由/多边形/魔棒、选区移动、复制剪切粘贴、蒙版载入及选区持久化，不能关闭完整 W-018 或 P-07。
