# M3 基础矩形/椭圆/魔棒/套索选区（2026-10-05）

当前生产窗口已接入矩形/椭圆/魔棒/套索选区工具、替换/加选/减选组合、清除选区和从图层 Alpha 载入按钮。选区是 `EditorWorkspace` 的会话内 `GrayTileRaster`，不写入 `.comp` manifest，不改变保存点；连续的选区状态保留在会话历史中，没有像素事务时可独立 Undo/Redo；新建、打开或导入工程会清除旧选区。选区拖动使用画布文档坐标，边界按像素边界稳定取整，并绘制在画布上；套索按指针路径使用像素中心的偶奇规则填充多边形。魔棒将当前合成预览转换为 RGBA 后调用 `NativeSelections.Select`，窗口提供点/3×3/5×5 取样半径、0–255 容差和连续选项；原生库由应用启动时按平台从应用目录解析。选区 mask 通过已有 `wand_trace` 转为闭合轮廓并叠加到画布，原生库不可用或轮廓过复杂时保留选区并回退到外接矩形显示。复制保留当前图层选区快照，剪切和粘贴使用同一选区位置进入像素历史；移动选区会将当前图层中选中像素和选区蒙版按整数偏移移动并裁剪画布外部分，移动像素的 Undo/Redo 同步恢复前后选区状态。

软笔构造时捕获当前选区快照，笔划提交只在选区覆盖范围内改变像素。完全落在选区外的笔划不会产生空历史步骤；选区内笔划仍只提交一步，可撤销。清除选区不标脏，也不进入图像历史。

## 固定验证

`CanvasChecks` 在固定窗口中完成：独立会话先建立两个矩形选区，未改像素时 Undo/Redo 恢复前后选区边界且工程保持干净；矩形拖选 30–150 × 30–120，得到 120×90 的不透明选区；复制不标脏；剪切产生可撤销历史并清除选中像素；粘贴恢复原选区位置且再次撤销可回到保存点；拖动选区 20×10 及反向拖动后像素与蒙版一起移动，撤销恢复像素及移动前边界，重做再次应用移动后的边界；从图层 Alpha 载入得到非空选区且不标脏；选区外笔划保持原像素且不产生历史；选区内笔划改变像素并可一次撤销；第二个矩形加选后覆盖 16,000 像素，减选后覆盖 14,000 像素；椭圆替换和三点套索均得到非空且小于外接矩形的覆盖；带已构建 `compositor_native` 动态库时启用 3×3 取样和 255 容差，魔棒在 128,128 点击得到非空选区、不标脏并返回非空闭合轮廓；缺少原生库的检查路径仍保留原选区并返回错误；清除选区后工程仍干净。原有软笔 exact、视图缩放/平移、100%/像素网格、保存导出及关闭取消回归继续通过。

该切片使用固定 Avalonia Headless 源码检查，未执行 Windows 物理鼠标、DPI、多显示器或性能验收。当前仍未接入浮动选区、工程蒙版载入及选区持久化，不能关闭完整 W-018 或 P-07；魔棒参数、原生轮廓显示和移动后选区状态撤销已接通，但尚不等于完整工具集。
