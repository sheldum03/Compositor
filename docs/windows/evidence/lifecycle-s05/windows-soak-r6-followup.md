这排除了“再正常等一分钟就会显著回落”作为本次现象的解释，也说明不可把回收前的存活弱引用直接判为泄漏。它仍不能单独证明 native 分配已全部释放或长期有稳定上限。GC 快照与当前进程采样不同步，不能直接相减得到精确 native 占用。

下一步先量化编辑、保存/重开、报告序列化各自的分配贡献；当前探针每十次编辑重写不断增长的完整报告，这部分开销需要单独测量，尚未确认它是根因。依据测量再决定是否优化诊断写出或采集 native 分配跟踪，不在产品中加入每轮强制 GC 来制造通过。`resourceAccepted=false`、S05 原标准与 M1 门槛保持不变。
