## 初步区分原因

在分析前按顺序列出三种假设：自然回收时点影响区间上限；关闭后资源逐步累积；测量记录分配增加。利用原始日志核查，不新增运行参数或修改应用。

1. **区间取样/自然回收波动得到支持，但未证明唯一因果。** 第 19–27 轮的上限仍低于第 1–9 轮已经出现的上限；11 次关闭后专用内存回落均伴随 Gen2 计数增加。中间九轮恰好较低，v1 将其当作后段的唯一上限参照。
2. **没有观察到旧文档持续持有或关闭后占用单调累积。** 后段最低值下降，句柄上限下降，最终旧文档弱引用为零。此结论只覆盖这些指标；仍不能证明所有原生分配无泄漏。
3. **没有观察到比前次更大的报告/托管分配规模。** 同样的轮次与记录量，总分配估计从 7,563,312,680 B 到 7,530,989,192 B（下降约 0.43%），最终托管存活从 7,976,152 B 到 7,912,800 B。这不支持“记录量增加导致本次失败”，也不把测量开销当作零。
