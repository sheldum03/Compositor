## 结论与后续

保留这次最小写出修改，消除测试报告对分配量的明显干扰。它没有解决全部编辑/导出分配，也没有改变生产文档的释放策略。剩余优先工作是按编辑、撤销重做、保存重开与渲染缓存的实际边界定位分配和保留来源，再用相同自然采样流程验证；不能加入每轮强制 GC 来制造通过，不能由一次更低的末尾值设置新资源容差。
