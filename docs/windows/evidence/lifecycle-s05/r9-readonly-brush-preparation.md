**本地已减少笔刷本身的分配，Windows 候选尚待实机验证。** R8 仍是先前冻结的独立 Windows 包，不能将 R9 本地结果计入 R8。

## 改动与不变量

R8 的核心阶段测量发现，每笔首次触及瓦片时先复制不可变源像素，再从这份副本复制工作像素。现在 `TiledRaster.ReadTile` 返回只读内存视图；缺失瓦片用空视图表示透明，工作 RGBA 仍独立分配。笔刷混合只读原始视图、只写工作缓冲。提交仍复制工作像素到新快照，未改变其所有权、历史、缓存或 GC 策略。没有全局缓冲池，也没有为压低测量结果强制回收。

新回归在实际 100 笔 / 2100 点路径上检查每次更新后与提交后原始快照摘要不变，固定最终摘要一致，再遍历 100 次撤销和重做。追加分配预算为提交像素量的两倍，用来捕获额外完整源副本，不能当作 S05 资源容差。
