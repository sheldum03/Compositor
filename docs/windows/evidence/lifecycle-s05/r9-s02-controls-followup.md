# R9 延迟问题的同环境控制（2026-09-23）

**原 R8 和此前通过版在当前环境均通过 S02 数值门槛，图像独立精确。** 这削弱了“当前机器普遍变慢”和“后续窗口启动逻辑本身导致失败”的解释，但每版本次只有一次控制执行，尚不足以确认 R9 分配变化与尾部延迟的因果关系。
