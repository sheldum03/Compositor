## 保留的实现与正确性

- 笔尾备份在一笔内按瓦片复用；撤回时恢复备份，仅重新混合笔尾可能影响的矩形。没有全局缓冲池。32 次预热区域更新分配从 33,590,744 降到 24,112 字节，预算 4 MiB。
- 图像缓存使用平台像素格式；仅轴对齐正向缩小、整数设备边界且可容纳于视口的瓦片采用设备尺寸缓存。其余情况使用全分辨率缓存。文档、历史、提交与导出分辨率不变。
- 缩小采样保留原画布坐标和矩阵；平移/缩放使采样缓存失效。曾尝试局部坐标缩放，但 37.5% 最近邻浮点舍入造成差异，已修正并加入回归。
- 缓存图像拥有独立 native 像素。托管数组仅在同步转换时短暂 pin，之后释放；替换缓存、结束测试时释放 native 对象。
- 264 张冻结图、960 组缓存与未缓存预览比较、覆盖率/混合穷举、默认及标量回退均通过。旧分配实现、过窄脏矩形、遗漏采样矩阵的三个负例均被回归捕获。见 [本地验证](tail-local-validation.json)。
- 五轮共十张 4000×4000 最终图与最初 Windows 基线 RGBA 精确一致。最终两轮额外读回各两张 1500×1500 原生预览，与同矩阵、同尺寸、同 RGBA8 premultiplied sRGB 的未缓存参考均为 **0 差异像素**。读回、参考绘制及 PNG 编码成本保留在每组最后一个测量更新内，没有扣除。
