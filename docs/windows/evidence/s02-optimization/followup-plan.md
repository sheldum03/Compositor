## 回归与不采用的实验

保留实现通过覆盖率 65,536 输入对 × 9 种长度、混合 256×256 输入组合、264 张冻结像素、临时笔尾/提交/撤销/重做/取消和三种缩放下半透明背景合成一致性。错误舍入及未改 Src 的去离屏版本分别被回归捕获。普通 40% 不透明度 brush 探针完成 242 更新 / 13 会话检查，S02 headless 完成 484 回调。Windows Release 可重建已测试 direct DLL，SHA-256 为 `11509e3e7ebb5e1ba7c918f4ea4cf90cd6e2491bef4930896826434aa91cbbce`；之后仅修正同一代码处过时注释并增强回归输入。

额外 alpha=0/255 分支仅做本地验证，未显示稳定收益，已撤回，未部署。GPU 实验同步 GPU 7503 次；两个最终测量更新还包含读回及参考生成，其成本保留在分布内。归档 PNG 统一解码 RGBA 后，空层/已有层有 54,429/102,039 个差异像素，最大通道差 7/8。报告直接比较 bitmap 字节的数字远大于 PNG 结果，且该探针没有强制参考 bitmap 与读回 bitmap 同一 ColorType，故不把原始字节差分解释成有效视觉误差；以独立 PNG 对照为准，仍未达到精确一致。默认软件路径不受影响。GPU 只是不采用此同步上传/绘制实验，不据此否定所有 GPU 方案。

GPU 实验源码以 [patch](gpu-diagnostic.patch) 归档，仅供重建当时诊断（包括上述读回比较限制）；不在当前执行入口内。其包身份见 [package](s02-gpucheck-package.json)，原始记录见 [archive](gpu-archive.json)。未测 VRAM 或物理显示完成时间；纯 headless 读回一致不代表 Windows GPU 一致。

## 尚未完成的目标及下一步

1. 已有层尾部延迟：以当前 direct 为基线，采集逐帧调度/CPU 栈，关联 >16.7 ms 帧；区分软件绘制耗时与错过渲染周期，先定位再改。通过标准仍为空层/已有层各至少 30 笔且 P95 ≤16.7 ms，不能用 P50、缩短计时或增加刷新率替代。
