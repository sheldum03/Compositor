# M3 受限平面文档尺寸（2026-10-05）

当前生产窗口新增“画布尺寸”和“图像尺寸”对话框，目标仍限于可编辑的平面 v8 工程。画布尺寸采用左上原点裁剪/扩展；图像尺寸使用最近邻 RGBA 缩放。每次操作重建所有平面图层的不可变瓦片快照，更新文档宽高和全画布 transform 元数据，形成一个像素历史步骤；选区在尺寸变化后清除。工程仍受 30,000 边长和 100 MP 上限约束。

## 固定验证

`CanvasChecks` 直接验证画布裁剪/扩展、左上像素保持、尺寸 Undo/Redo，以及最近邻图像缩放后的新尺寸。`NewDocumentChecks` 通过正式 Avalonia 窗口实际打开两个对话框，将已保存的 259×257 工程改为 240×250 和 130×129，分别用 Undo 恢复原尺寸和保存点。无原生库及带 `compositor_native` 动态库的 AppChecks 均通过，构建 0 警告、0 错误。

该切片未覆盖高质量插值、非破坏 transform、旋转/自由扭曲、组/蒙版、DPI 重采样策略、Windows 原生对话框或性能；W-020 仍未完成。
