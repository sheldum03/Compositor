# M3 受限平面图层翻转（2026-10-05）

生产窗口新增“水平翻转”和“垂直翻转”按钮。当前编辑器只开放全画布、平面、Normal/支持的外观图层，因此翻转按当前图层的完整 RGBA 像素做破坏式镜像；不修改 manifest 的 transform 字段，也不声称已经支持非破坏移动、缩放、旋转或组/蒙版变换。每次翻转通过 `EditorWorkspace.FlipActiveLayer` 只替换活动图层一次，预览沿用同一合成器，像素事务可撤销/重做。

## 固定验证

`CanvasChecks` 在正式 Avalonia Headless 窗口中保存笔刷回归结果后，对活动图层执行水平翻转，逐字节与独立镜像参考比较；Undo 恢复翻转前像素，Redo 再次得到镜像。随后执行垂直翻转并用相同方式比较和撤销，最终保存/重开仍与原有 `CrossTile-final.rgba` 及导出一致。无原生库和带 `compositor_native` 动态库的两条窗口检查均通过，构建 0 警告、0 错误。

该证据未验证 Windows 物理输入、DPI、非平面图层、组、蒙版、旋转、缩放、裁剪或性能；W-020 仍未完成。
