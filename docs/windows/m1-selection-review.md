## 决策闭合条件

- D-02：补原生文字、连续笔刷和运行可靠性后，按证据选择一条生产路线；当前只记录 Avalonia 性能证据领先，不提前将其写成已选型。
- D-03：当前软件 CPU 路径已证明本机 S02 可行；Mac CPU/Metal 参考差异的语义和容差仍需明确。不得用新的缓存通过记录自动放行跨平台像素差异。
- D-05：保存栅格保真、编辑后平台重排已有设计建议；缺字体处理、变换后的原生输入完整组合仍需验证。
- D-06：S02 本机数值通过；S05 关闭后自然内存增长尚待定位，设备矩阵未齐；不能静默设定更宽资源容差。
- D-07：依赖、字体、模型的具体发行清单与许可处理尚未全部闭合。既有私有测试包不是最终发行许可或安装验收。

## 生产推进顺序

M1 条件满足后，按已有 [W-010–040 计划](development-plan.md) 开始单一生产入口：先建立构建与 CI、文档事务/历史、像素核心、受保护的工程读取、安全保存与基础 IO。第一条可验收交付路径为“读取→编辑→撤销/重做→安全保存→重开→导出”，并做保存中断故障检查。之后串联 Alpha，再实现文本/字体、高级编辑、AI/完整兼容、Beta 和安装更新验收。当前没有生产框架决定，也未新增空壳生产 UI 来冒充第四项完成。
