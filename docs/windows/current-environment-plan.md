# 当前环境可执行开发计划

更新日期：2026-10-07  
实施分支：`codex/windows-implementation`  
当前环境：macOS arm64；仓库没有可用的 `dotnet` 命令，因此本轮只做静态检查、源码级验证和可独立运行的脚本检查。

## 执行原则

1. 先完成不依赖 Windows API、Windows 设备、IME、GPU 驱动或外部模型的代码。
2. 每个切片只解决一个可验证目标，单独提交，避免把未验证的功能包装成完成。
3. 旧工程遇到未支持语义时保持只读；兼容的 v1–v7 工程只在内存中升级到 v8，明确保存后才写回。
4. 不能在当前环境验证的项目保留为阻塞项，转移到 Windows 实机、干净虚拟机或模型/解码器依赖到位后的阶段。
5. 当前用户已要求跳过验收、设备矩阵和发布检查，因此这些项目不作为本轮完成条件，也不伪造通过记录。

## 后续实现顺序

### 第一阶段：核心数据安全

1. 完成 A5 的代码审阅，确认复制后的 `id`、`imageFile`、`maskFile`、`maskSourceID` 和历史快照互不共享。
2. 检查所有新增图层入口是否复用同一命名、像素预算和资产校验路径。
3. 只对已存在的保存回滚逻辑补边界；不顺手重构无关代码。

验证方式：静态调用链检查、`git diff --check`、无 `dotnet` 时记录为未编译；恢复和像素逐项验证留到 SDK 可用时执行。

### 第二阶段：跨平台可移植包工具

1. 定义便携包目录契约：入口可执行文件、原生库、运行库清单和版本文件。首个切片默认入口是 `Compositor.App.exe`。
2. 已编写 PowerShell 安装脚本：拒绝正在运行的实例，校验包路径和 SHA-256，将包解压到唯一暂存目录，验证入口后替换安装目录。
3. 已保留用户数据目录参数，不把工程、字体、模型和设置放入替换目录。
4. 已实现失败回滚和成功后的暂存/旧目录清理；Windows 文件锁和 ACL 仍需实机验证。
5. 已编写只读 Python 检查器，验证包 hash、路径穿越、重复文件和入口文件，不执行压缩包内容。

验证方式：PowerShell 语法/路径分支静态审阅，Python 检查器在 macOS 上运行固定临时目录；Windows 文件锁、ACL、快捷方式和卸载行为留到 Windows 阶段。

### 第三阶段：当前分支代码收口

1. 搜索所有 `TODO`、`FIXME` 和 `NotSupportedException`，按“可安全实现 / 需要产品决定 / 需要 Windows 或外部依赖”分类。
2. 对可安全实现项逐个切片：数据复制、资产校验、撤销状态、错误消息和文档；不通过添加空按钮来降低未完成数量。
3. 对依赖 Windows 的项补清晰的能力检测和用户提示，确保失败不会覆盖工程或丢失当前选区/笔划。
4. 每完成一个切片，更新 `docs/windows/execution-log.md` 和本计划状态。

验证方式：代码差异审阅、调用链完整性检查、错误分支检查；不把静态检查写成运行通过。

## 当前环境无法完成的任务

| 类别 | 阻塞原因 | 处理方式 |
| --- | --- | --- |
| Windows GUI/窗口行为 | 当前主机没有 Windows 桌面和 Windows SDK | 保留 Avalonia 代码与能力检测；到 Windows 实机验证窗口、文件夹选择、剪贴板和安装。 |
| IME/候选窗/高 DPI/多显示器 | 依赖 Windows 输入法、显示器和驱动 | 保留文本布局和焦点边界；到 Windows 验证候选窗、缩放、旋转命中和多屏坐标。 |
| 原生 DLL 的 Windows 运行 | 当前没有 MSVC/Windows 运行时 | CI 或 Windows 机器验证导出、P/Invoke、运行库和实际启动。 |
| TIFF/HEIC/ICC | 需要选定解码库、许可证和 Windows 分发包 | 先保持 PNG/JPEG 明确边界；M6 评估并锁定依赖后再实现。 |
| AI 去背景 | 需要模型权重、许可证、运行时和效果样本 | 先设计离线 provider/cache 接口；模型选择和效果验收留到 M6。 |
| 性能与设备输入 | 需要真实 4K/100MP 场景、数位笔和 Windows GPU | 当前只保留算法契约和性能日志入口，不宣称达标。 |
| 签名、正式安装器、更新发布 | 需要证书、发布源、干净 Windows 机器和用户授权 | 只实现本地包校验/回滚脚本；签名与发布不在当前分支执行。 |

## 阶段出口

- **当前环境完成**：代码切片已提交；静态检查无新增格式错误；文档准确列出限制。
- **可交给 Windows 验证**：入口、包结构、依赖清单和失败提示已准备；Windows 实机只需执行验证矩阵。
- **不得提前标记完成**：Windows GUI/IME/DPI、真实设备性能、TIFF/HEIC/ICC、AI 模型、签名安装器和正式发布。
